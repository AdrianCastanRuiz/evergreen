# @evergreen/mobile

Expo React Native app (family/staff) for Evergreen. Expo SDK 57, expo-router, NativeWind 4 + React Native Reusables, TanStack Query with AsyncStorage persister (AD-16), tokens in platform keychain via expo-secure-store (AD-8).

```bash
pnpm --filter @evergreen/mobile run dev
```

See `_bmad-output/implementation-artifacts/spec-16-mobile-scaffold-expo.md` for the scaffold spec.
